# The-Gambia-pneumonia-shotgun-metagenomics

Shotgun metagenomic profiling of bacterial microbiomes, metagenome-assembled
genomes (MAGs), and antimicrobial resistance in respiratory and blood samples
from Gambian children with pneumonia.

**Preprint:** [Research Square, DOI: 10.21203/rs.3.rs-8724320/v1](https://doi.org/10.21203/rs.3.rs-8724320/v1)

**Status:** Manuscript currently under peer review (major revisions in progress).

**Code:** The analysis code will be published here once the revision is complete

## Summary

This project used shotgun metagenomic sequencing of respiratory and blood
specimens from Gambian children with pneumonia to characterise bacterial
microbiome composition, recover metagenome-assembled genomes (MAGs), and profile
antimicrobial resistance determinants from the recovered MAGs
